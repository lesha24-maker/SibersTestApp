# 🏰 Crystals & Dragons (Кристаллы и Драконы)

![Language](https://img.shields.io/badge/Language-Swift_5-orange) ![Platform](https://img.shields.io/badge/Platform-iOS-lightgrey) ![Architecture](https://img.shields.io/badge/Architecture-MVVM-blue) ![Framework](https://img.shields.io/badge/Framework-SwiftUI-green)

Добро пожаловать в текстовую RPG-игру, разработанную в качестве тестового задания на вакансию **iOS Developer**. Проект представляет собой классический "Dungeon Crawler", где игрок исследует процедурно генерируемый лабиринт, собирает предметы и сражается с монстрами.

---

## 📋 О проекте

Приложение имитирует работу консоли на экране iPhone. Игрок управляет персонажем текстовыми командами, перемещаясь по сетке комнат в поисках Ключа и Сундука с Граалем.

**Главная цель:** Найти 🗝️ Ключ, найти 📦 Сундук, открыть его и выжить.

---

## ✨ Реализованный функционал

В проекте выполнены **все обязательные требования** и **дополнительные задания (Bonus Tasks)**:

### 🧩 Основная механика

*   **Генерация лабиринта:** Карта создается заново при каждом запуске. Алгоритм гарантирует связность комнат (нет изолированных участков). Используется алгоритм обхода в глубину (DFS) для создания связанного лабиринта.

*   **Перемещение:** Система координат `[x, y]` и переходы по сторонам света (N, S, W, E).

*   **Инвентарь:** Возможность подбирать (`get`) и выбрасывать (`drop`) предметы.

*   **Условия победы/поражения:** Победа при открытии сундука, проигрыш при окончании шагов (здоровья).

*   **Проверка проходимости:** Алгоритм гарантирует, что ключ и сундук всегда достижимы в пределах лимита шагов.

### 🔥 Дополнительные задания (Bonuses)

*   **🌑 Тёмные комнаты:** Если в комнате темно, игрок не видит описания и дверей. Требуется 🔦 **Факел** (torchlight) или удача. Если выбросить факел в темной комнате — она освещается навсегда.

*   **🍎 Еда:** Предметы, восстанавливающие жизненные силы (лимит шагов). Команда `eat [item]`.

*   **👾 Монстры и Таймер:** Реализована механика реакции. У игрока есть **5 секунд** на действие при встрече с монстром. Если замешкаться — монстр атакует первым! Три возможных исхода: полный провал, частичный успех с уроном, полный успех.

*   **⚔️ Боевая система:** Команда `fight`. Если есть **Меч** (sword), монстра можно убить. Без меча — исход зависит от удачи (RNG). С мечом шансы на победу выше.

*   **💰 Золото:** Сбор монеток для подсчета очков. Отображается как `gold (XXX coins)`. Команда `get gold`.

*   **🎨 Цветной текст:** Реализована поддержка цветов в консоли для лучшего восприятия:
    - ⚪ Белый — обычные сообщения
    - 🟢 Зеленый — успешные действия
    - 🔴 Красный — ошибки и опасность
    - 🟡 Желтый — предупреждения
    - 🔵 Голубой — информационные сообщения

## 🛠 Технический стек и Архитектура

Проект написан на **Swift** с использованием **SwiftUI**.

В основе лежит архитектурный паттерн **MVVM (Model-View-ViewModel)** для разделения логики и отображения.

### Структура проекта:

```
SibersTest/
├── Models/
│   ├── Direction.swift      # Направления движения (N, S, W, E)
│   ├── Item.swift           # Типы предметов (key, chest, torchlight, food, sword, gold)
│   ├── Monster.swift        # Монстры с именами
│   ├── Room.swift           # Комната лабиринта (координаты, двери, предметы, монстры)
│   ├── Player.swift         # Игрок (позиция, инвентарь, здоровье, золото)
│   └── Maze.swift           # Генератор лабиринта (DFS алгоритм)
├── ViewModels/
│   └── GameViewModel.swift # Логика игры, обработка команд, управление состоянием
└── Views/
    └── GameView.swift       # SwiftUI интерфейс с цветным выводом
```

1.  **Model (Модель):**

    *   `Room`, `Player`, `Item`, `Monster`, `Direction` — структуры данных игры.
    *   `Maze` — класс генерации карты (использует алгоритм обхода в глубину для создания связанного лабиринта).

2.  **ViewModel (Модель представления):**

    *   `GameViewModel` — "Мозг" игры. Хранит состояние, обрабатывает текстовый ввод, управляет таймерами монстров и логикой игры. Использует `@Published` свойства для реактивного обновления UI.

3.  **View (Представление):**

    *   `GameView` — SwiftUI интерфейс. Отвечает за отображение цветного текста и прием ввода с клавиатуры.

> **Почему MVVM?**

> Это стандартный паттерн для SwiftUI приложений. Он позволяет легко тестировать игровую логику отдельно от интерфейса, а также делает код чистым и расширяемым. Код не свален в один массивный View.

### Особенности реализации:

*   ✅ Используются только стандартные фреймворки iOS (Foundation, SwiftUI, Combine)
*   ✅ Нет сторонних зависимостей
*   ✅ Чистая архитектура с разделением ответственности
*   ✅ Реактивное программирование через `@Published` и `ObservableObject` (Combine)
*   ✅ Асинхронная обработка таймеров монстров

## 🚀 Как запустить

1.  Клонируйте репозиторий или скачайте архив.

2.  Откройте файл `SibersTest.xcodeproj` в **Xcode**.

3.  Выберите симулятор (например, iPhone 15) в верхней панели.

4.  Нажмите `Cmd + R` (Run).

5.  Игра запустится в симуляторе. Введите количество комнат и нажмите "Start Game". Затем вводите команды в нижнее текстовое поле и нажимайте "Send" или `Return` на клавиатуре.

## 🎮 Список команд

| Команда | Описание |
| :--- | :--- |
| `N`, `S`, `W`, `E` | Перемещение (Север, Юг, Запад, Восток) |
| `get [item]` | Подобрать предмет (например, `get key`, `get torchlight`) |
| `drop [item]` | Выбросить предмет |
| `get gold` | Собрать всё золото в комнате (формат: `gold (XXX coins)`) |
| `eat [item]` | Съесть еду для восстановления здоровья (например, `eat food`) |
| `open` | Попытаться открыть сундук (нужен ключ в инвентаре) |
| `fight` | Атаковать монстра (желателен меч в инвентаре) |

### Примеры игрового процесса:

```
You are in the room [2,3]. There are 3 doors: [E, N, S]. Items in the room: [key, torchlight].
Steps remaining: 95 | Health: 95% | Gold: 0

> get key
You picked up key!

> get torchlight
You picked up torchlight!

> N
You are in the room [2,2]. There are 2 doors: [S, W]. Items in the room: [chest].
Steps remaining: 94 | Health: 94% | Gold: 0

> open
You opened the chest and found the Holy Grail! You win! 🎉
```

## 🎯 Игровые механики

### Тёмные комнаты 🌑
- При входе в тёмную комнату без факела игрок видит только: `Can't see anything in this dark place!`
- С факелом в инвентаре комната видна нормально
- Если выбросить факел в тёмной комнате, она остаётся освещённой навсегда

### Монстры 👾
- При встрече с монстром у игрока есть **5 секунд** на ввод любой команды
- Если не успеть — монстр атакует (потеря 10% здоровья, откидывание назад)
- Если успеть — три возможных исхода:
  - 33%: Полный провал (урон + откидывание)
  - 33%: Частичный успех (команда выполнена, но урон получен)
  - 33%: Полный успех (команда выполнена без урона)

### Боевая система ⚔️
- Команда `fight` работает только если есть меч в инвентаре
- С мечом шансы на победу выше (33% полный провал, 33% победа с уроном, 33% победа без урона)
- После победы монстр исчезает из комнаты

### Здоровье и шаги 💚
- Начальное здоровье: 100 шагов
- Каждое перемещение тратит 1 шаг
- Еда восстанавливает +20 шагов
- Монстры отнимают 10% от максимального здоровья
- При достижении 0 шагов — игра окончена
